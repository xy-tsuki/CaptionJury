字幕对照组（CaptionJury）：把中日混说的视频或音频转成带时间轴的字幕。

安装内容
- 字幕对照组程序本身，以及转换音频用的 FFmpeg。
- 如果电脑上还没有 Microsoft Edge WebView2 运行时（程序界面要用），会顺便安装。

第一次打开时
程序会引导你下载语音识别运行库（CrispASR，约 40 MB 到 570 MB，取决于显卡）和两个必装模型（约 3.5 GB）。这些文件放在 %LOCALAPPDATA%\Tingxie，不占安装目录。下载失败会自动换来源，中途中断可以接着下。

电脑要求
- Windows 10 或 11，64 位。
- 独立显卡。NVIDIA 显卡用 CUDA 版（需要 580 以上版本的驱动），其他显卡用 Vulkan 版。
- 校对功能需要 DeepSeek API 密钥，可以以后在设置里填写；不填也能出字幕。

隐私
音视频只在本机处理。开启校对时，只把识别出的文字发给 DeepSeek。

本程序暂未进行代码签名，Windows 可能提示"未知发布者"，选择"仍要运行"即可。
第三方组件的许可证见安装目录下的 licenses 文件夹。
