字幕对照组（CaptionJury）：把中文、日语的视频或音频转成带时间轴的字幕。

安装内容
- 字幕对照组程序本身，以及转换音频用的 FFmpeg。
- 如果电脑上还没有 Microsoft Edge WebView2 运行时（程序界面要用），会顺便安装。

第一次打开时
程序会引导你下载语音识别运行库（CrispASR，约 40 MB 到 570 MB，取决于显卡）和两个必装模型（约 3.5 GB）。这些文件放在 %LOCALAPPDATA%\CaptionJury，不占安装目录。下载失败会自动换来源，中途中断可以接着下。

电脑要求
- Windows 10 或 11，64 位。
- 最好有独立显卡。程序会按显卡和驱动自动选 CUDA 或 Vulkan 版；没有可用显卡时也能用 CPU 跑，但慢很多。
- AI 校对可以用 DeepSeek 等服务商的 API 密钥，也可以把提示词复制给你订阅的 Agent；不开也能出字幕。

隐私
音视频只在本机处理。开启 AI 校对时，只发送识别出的文字。

本程序暂未进行代码签名，Windows 可能提示"未知发布者"，选择"仍要运行"即可。
第三方组件的许可证见安装目录下的 licenses 文件夹。
