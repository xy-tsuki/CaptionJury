# 路线图

## 定位
本机运行、免费的中日字幕工具。要宣传的三点：

1. **多模型对照，精度高**：几个识别模型各听一遍，AI 按多数纠错，拿不准的标出来给人选。
2. **界面直观，好上手**：默认选项就能出好结果，不需要懂模型和参数；订阅制 AI（复制给 Agent）也能用，不一定要 API。
3. **中文和日语都能用**：中日混说、纯中文、纯日语都支持，以后加英语。

### 宣传口径
- 一句话：**免费，中日混说也准，每句能对照改。**
- 免费是让人来试的理由：剪映的自动字幕要开 VIP，达芬奇要付费的 Studio 版才有自动字幕（发宣传前再核实一次）。
- 精度和校对体验是留下来的理由：免费的同类工具（SmartSub、Buzz 等，多基于 Whisper）也不少，光靠免费比不过它们。
- 「免费」要说准确：快速模式完全免费，只用本机显卡；精准模式的 AI 校对可以走接口（要花钱，DeepSeek 一段视频约几分钱），也可以复制给自己订阅的 Agent。写「免费，可选接入 AI 校对」，不写「全部免费」。
- 强调「中日混说的同一段视频」，而不是「中日都支持」：支持多语言的工具很多，混说才是我们的差异。
- 精度只说评测得出的数字（见阶段 0），并和 SmartSub（Whisper large-v3）、剪映在同一批视频上对比。

### 和别家的区别
- SmartSub：功能多、上限高，但上手慢，只能走 API。我们只做好转写和校对这一件事，先做准、再做易用。
- 剪映：中文识别强、和剪辑一体，但自动字幕收费；纯中文用户不是我们的主战场，日语和中日混说内容才是。

## 面向的用户（按优先级）
1. **视频创作者**：剪完视频打字幕，对标剪映的智能字幕，但免费。导出要能直接进剪映、Premiere、达芬奇、Final Cut。
   - 先从**达芬奇用户**切入：免费版没有自动字幕，他们本来就在找免费方案，也习惯在剪辑软件外处理音视频。
   - 重点是做日语、中日混说内容的创作者和切片作者，这部分剪映服务得不好，也和字幕组重合。
2. **字幕组**：中文或日语内容的切片；以后加英语，面向搬运海外视频的人。需要翻译和统一的术语。
3. **会议和课程记录**：留学生和海外用户。需要长音频、说话人和文字稿。

## 阶段 0：评测基础（贯穿始终）
- `tests/cer_kana.py`：按读音算字错率（写法不同不算错），一次跑多段「参考稿 + 结果」，分别算各模型和最终结果。
- 收集 3–5 段不同类型的参考稿：纯日语、中日混说、多人对谈、带背景音乐。参考稿只放本机，不进仓库。
- 宣传里的精度数字只用这套评测的结果；每次改识别或校对，都跑一遍确认没有变差。

## 阶段 1：视频创作者
- 新建页改成三种模式：快速、精准（默认）、自定义。精准模式没配置校对 AI 时直接提示。
- 导出：
  - 保留逐字时间，按逐字时间切条；
  - 按用途选每条字数：横屏、竖屏、不限；
  - 已有「去掉标点」「字幕带说话人」两个选项。
- 确认 SRT 能直接导入剪映、Premiere、达芬奇、Final Cut；只有出问题时才加 FCPXML / iTT。
- 导出后告诉用户在各剪辑软件里从哪里导入。
- 首次上手：引导页下完模型后用快速模式试转一个文件；校对页第一次打开时说明颜色的意思。
- 新建页按历史速度估算各模式要多久。

## 阶段 2：字幕组
- 翻译：沿用这次转写的大纲和词库，保证人名、术语前后一致；可以用接口，也可以复制给 Agent；校对页能对照原文。
- 双语字幕导出（原文和译文上下两行，ASS 里分两种样式）。
- 词库能按频道或系列保存、复用。
- 英语识别：Qwen3-ASR 本身支持英语，要补模型清单、断句规则和校对提示词。

## 阶段 3：会议和课程
- 长音频（1–3 小时）的稳定性、进度和中途恢复。
- 说话人命名，导出时带名字。
- 带时间戳和说话人的文字稿（TXT / DOCX）。
- 可选的 AI 纪要。

## 阶段 4：分发、Mac 版和宣传
- **Mac 版**（Final Cut 用户都在 Mac 上，做出来面向的创作者会多很多）：
  - 先在一台苹果芯片的 Mac 上确认 CrispASR 能跑这几个模型（ggml 有 Metal 加速），速度能接受再继续；
  - pywebview 和 ffmpeg 可以沿用；密钥加密从 DPAPI 换成钥匙串；运行库和模型下载要加 Mac 版本；
  - 安装包重做，最好做签名和公证，否则会被 Gatekeeper 拦下。
  - 和宣传同时或稍早做。
- CrispASR 运行库放进本项目的备份，方便中国大陆下载（先确认 NVIDIA CUDA 运行库的再分发条款）。
- README 加效果图，用阶段 0 的评测数字写介绍。
- 考虑代码签名，去掉 SmartScreen 的「未知发布者」提示。
