# 开发日志

新的在上面。

## 2026-11-09
- 仓库改为公开；私人录音的参考稿移出仓库，只留在本机。
- 新增模型清单 `core/models.py`，默认路径改到数据目录，不再写死 `E:\AI`。
- 每种语言可以同时启用多个备用模型，接入 Whisper；设置页按语言勾选。
- 修复：没有标点的备用结果（Whisper）按句切分时每句错位一个字。
- 模型下载器：设置页选来源下载，断点续传、SHA-256 校验、失败自动换源；三个来源是 Hugging Face、hf-mirror 镜像、本项目 GitHub 备份（尚未上传）。
- 建立 git 仓库和 GitHub 私有仓库，补 AGENTS.md、开发日志、决策记录、CI 和 PR 模板。
- 新增字错率评测 `tests/cer.py`，用户校对好了小米眼镜片段的参考稿。
- 切块改成按总长平均分：原来最后会剩一小块（8 秒），Qwen 几乎什么都没听出来。Qwen 的字错率从 23.4% 降到 21.6%。
- 试过但没采用：响度标准化、20 / 25 秒块、5 秒重叠、本地逐字投票。前三个的结果随参数在 20% 到 24% 之间来回变，算不上稳定的提升；投票只提升约 0.5 个百分点。
- 估算上限：至少有一份结果听对的字占 91%，Qwen 单独只对 78% 左右，剩下的提升要靠合并几份结果。
- DeepSeek 校对改成分批并发（每批约 30 句，带前后文），并加程序校验：结构错误打回重写一次；内容和各份识别结果对不上的标成存疑，交给用户选。提示词加了示例。
- 对比 Whisper large-v3 q5_0：小米眼镜片段的字错率 28.6%（Qwen 21.6%），结尾凭空多出一句话；东京片段 37 秒以后时间戳全乱。但它的错误和 Qwen 不同，速度又快，适合当备用模型。
